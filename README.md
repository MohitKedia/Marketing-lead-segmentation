# Marketing-lead-segmentation using K-Means clustering

🚀 Project Overview

This project builds a Marketing Lead Segmentation System using K-Means Clustering to classify business leads into:

🔥 Hot Leads (High Value)
🌤️ Warm Leads (Medium Value)
❄️ Cold Leads (Low Value)

The project analyzes customer behavior and engagement patterns to determine how important a lead is for the business.

This is a beginner-friendly yet industry-style Machine Learning project suitable for:

Data Analyst Portfolio
Machine Learning Engineer Portfolio
Marketing Analytics Projects
GitHub Resume Projects
